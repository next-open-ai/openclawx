# SDD 与代码评审清单

## 规格与范围

- [ ] 已检查工作区并确认未覆盖用户或其他任务的改动。
- [ ] 有稳定任务 ID，并关联需求、设计和测试。
- [ ] 变更没有违反 Accepted ADR；若改变决策，已有替代 ADR。
- [ ] 公共契约、配置迁移、错误码和状态转换已经定义。
- [ ] 实现没有超出任务授权范围。

## 模块边界

- [ ] 模型 SDK/HTTP 只由 `packages/agent-core` 使用。
- [ ] 公共 Schema 以 `@openclawx/contracts` 为单一事实源。
- [ ] 编排状态和循环位于 `@openclawx/orchestrator`。
- [ ] renderer 不直连模型、不读取凭据、不 import Node/Electron。
- [ ] Tool/MCP 没有隐式承担模型路由。

## 安全与数据

- [ ] 密钥不进入 domain KV、事件、日志、Prompt 或前端。
- [ ] 模型输出不能绕过工具权限或直接执行。
- [ ] 重试、修复和 Agent Loop 有硬上限。
- [ ] 外部模型不会被静默调用。
- [ ] 日志、Verifier 错误和回流数据已经脱敏。

## 测试与交付

- [ ] 契约、迁移、错误、取消和并发路径有测试。
- [ ] 执行了任务指定的测试、类型检查和构建。
- [ ] `traceability.md` 与 `status.md` 已更新。
- [ ] 阶段完成时有 Deliverable，明确已交付、未交付和风险。
- [ ] 回滚路径已说明并在高风险变更中验证。
- [ ] 文档路径或导航变化已执行 `pnpm docs:build`。
- [ ] 最终报告区分通过、失败、未执行、不适用和风险接受。

## 可维护性

- [ ] 没有新增重复事实源、重复 Schema 或隐式状态所有者。
- [ ] 错误、取消、超时、重试和幂等语义明确。
- [ ] 新日志和指标足以定位问题且不泄漏敏感数据。
- [ ] 变更规模与任务目标相称，相邻问题没有被顺手混入。
