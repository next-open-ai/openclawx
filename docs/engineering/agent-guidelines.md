# 编码智能体规则导读

仓库根目录的 `AGENTS.md` 是编码智能体规则的唯一事实源。本页只提供文档站内的阅读导引，不替代根规则。

## 必须遵守的核心边界

- 公共行为变更必须有可运行回归；
- Renderer 不得直接依赖 Electron 或 Node；
- 只有 `packages/agent-core` 可以调用模型 SDK；
- 公共契约以 `@openclawx/contracts` 为单一事实源；
- 编排状态由 `@openclawx/orchestrator` 管理；
- 域数据保持单写者，密钥不得进入领域数据；
- 公共行为和跨包接口使用稳定需求、任务与测试 ID；
- 文档完成、代码实现和测试通过必须分别记录，不得虚报状态。

## 阅读顺序

1. 根目录 `AGENTS.md`；
2. [工程规则](README.md)；
3. [全局架构](../architecture/architecture.md)和相关 Accepted ADR；
4. 当前功能 SDD 的总览、任务、契约、测试与状态；
5. [评审清单](review-checklist.md)。

## 每次任务的最小输出

- 说明实际修改范围和未修改范围；
- 列出执行过的测试、构建和文档检查；
- 明确未执行项、阻塞和剩余风险；
- 公共行为变化时同步 SDD、追踪关系和状态；
- 不将推测、计划或文档完成描述成已经实现或验证。

在源码仓库中工作时，请始终直接读取根目录 `AGENTS.md` 获取完整、最新规则。
