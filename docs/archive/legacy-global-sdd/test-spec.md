# OpenClawX 测试规格（历史总规格）

> 状态：历史参考。当前测试策略见 [测试与质量中心](../../quality/README.md)，新功能测试规格进入 [功能 SDD](../../sdd/README.md)。

## 1. 测试层级

| 层级 | 覆盖目标 | 方式 |
| --- | --- | --- |
| 静态检查 | Vue/TS 类型、跨包契约、构建入口。 | `pnpm --filter @openclawx/renderer typecheck`，各包 build。 |
| 单元测试 | 调度日期、权限判定、路径归一化、项目状态变迁。 | Vitest（后续补充）。 |
| 集成测试 | Fastify SSE、Agent 工具事件、Electron IPC、SQLite 与资产归档。 | 临时工作区 + mock Provider。 |
| 端到端/人工验收 | 桌面窗口、流式 UI、审批与实际模型任务。 | Electron 开发环境与发布包。 |

## 2. 项目编排验收场景

| 编号 | 前置条件 | 操作 | 期望结果 |
| --- | --- | --- | --- |
| T-PRJ-01 | 至少一个模型已配置。 | 创建项目并输入目标，生成草案。 | 得到 2–5 个独立任务；项目仍为 `draft`，没有 Agent 运行。 |
| T-PRJ-02 | 草案已生成。 | 编辑任务员工/目标后确认。 | 修改被持久化；任务默认 `draft`，只有点击启动才转为 `queued`。 |
| T-PRJ-03 | 两个无依赖任务，模型可用。 | 启动项目。 | 两个任务近似同时进入 `running`；当前聊天的员工、会话和消息不发生变化。 |
| T-PRJ-04 | 任务配置了选中 Skill。 | 执行任务并观察工具事件。 | 运行时仅获得该员工已授权的选中 Skill；未授权 Skill 不可调用。 |
| T-PRJ-05 | 任务选择只读权限。 | 要求写文件或脚本执行。 | 工具拒绝并产生可解释的权限/审批事件。 |
| T-PRJ-06 | 任务生成 PDF/XLSX。 | 等待任务完成并打开资产库。 | 资产自动归档，带员工与运行来源；可下载。 |
| T-PRJ-07 | 一个任务成功、一个任务失败。 | 等待汇总。 | 汇总只使用成功任务结果；项目/运行显示失败并保留成功产物。 |
| T-PRJ-08 | 项目运行中且仍有排队任务。 | 点击取消。 | 排队任务变为 `cancelled`；已开始任务不被强制中断；运行记录完整。 |
| T-PRJ-09 | 有失败任务。 | 点击重试后再次启动。 | 仅失败/排队任务重跑，`attempts` 增加，历史结果不丢失。 |
| T-PRJ-10 | 项目完成后重启应用。 | 打开项目页与运行记录。 | 项目、任务结果、失败信息和汇总仍可查看。 |
| T-PRJ-11 | 分别创建瀑布、并发、讨论、DAG 模板。 | 启动项目并观察任务状态。 | 瀑布按顺序运行；并发根任务并行；讨论主持任务等待观点任务；DAG 仅在所有前置成功后启动。 |
| T-PRJ-12 | 项目正在运行且有多个任务。 | 在运行工作台切换任务卡片。 | 总览同时展示各任务状态；右侧只显示所选员工的流式输出、工具过程、错误和资产。 |
| T-CHAT-01 | 普通对话模型可用。 | 选择 1–3 位协作者并发送请求。 | 协作者并发显示在主答复的协作卡片；主员工在协作者完成后生成综合答复。 |
| T-CHAT-02 | 普通对话已选择协作者。 | 要求写文件或运行脚本。 | 协作者以只读权限运行，不产生绕过审批的写入或脚本执行。 |

## 3. 安全与回归检查

- 尝试使用 `../`、绝对路径、符号链接越界读取或写入：必须拒绝。
- “完全权限”下尝试删除工作区外文件：必须拒绝或要求独立的危险操作确认。
- 未配置模型、模型流返回非法 JSON、模型中断：草案生成有清晰错误或本地保守草案；UI 不崩溃。
- 并行任务分别生成同名文件：资产索引不得覆盖，文件应按运行目录隔离。
- 大量工具过程或长答案：执行过程折叠/限高，聊天输入框保持可见。
