# 项目续聊与输入能力 · PC-V1

范围：Workmate。沿用 ProjectService / ChangeSet / DAG / RunEngine，不新增聊天执行器，不修改其他子项目。

## 需求、任务、契约与测试

- PC-R1/T1：完成/失败/取消的项目可直接输入并发送，不强制先 @。默认选择最后发言且仍在项目中的员工，否则最后一个有效任务员工；可切换。运行中禁止重复发送并提供停止入口；无成员显示说明。服务端仍校验成员和写权限。
- PC-R2/T2：抽取项目输入组件，支持 Enter 发送、Shift+Enter 换行、IME 不误发、@成员、发送等待态；异步提交成功后才清空，失败保留草稿/文档并显示原错误。项目切换隔离草稿。回复复用员工模型/技能/审批，保留项目目录和上游成果，仅目标及下游增量调度；不是全量再次调度。续聊保留上次目标任务回复作为有界上下文，优先当前要求。任务回复以 Run ID 独立关联和持久化，连续追问不覆盖旧回答；旧项目续聊前从实际已结束 Run 补齐缺失回复。
- PC-R3/T3：参考文档复用既有解析和工作流文档组件，支持选择/拖放/粘贴文件、重试/移除、10 个/50 MB、仅附件发送。上传失败不得发送。语音输入复用 VoiceInputDialog，识别后填入文字，用户确认发送，不自动执行。
- PC-R4/T4：新增 POST `/projects/:id/uploads/:requestId`，复用二进制文档上传；增量指令增加可选 requestId/fileIds（UUID，最多10个、去重）。上传作用域按组织/用户/项目/请求隔离；只有可写项目可上传/提交。原件及节选写入服务端项目目录的 inputs/，不接受客户端目录，不覆盖旧文件/链接，不归档为交付物。旧文本请求兼容；未发送附件沿用已有过期清理。附件不授予额外工具权限。

非目标：本期不复制普通聊天的多协作者、自动调度开关、独立模型覆盖、图片视觉输入或实时全双工对话；避免绕过项目 DAG 与员工授权。旧本地项目支持文字/语音输入，文档上传仅普通服务端管理项目提供；隔离运行的数据应用项目暂不提供文档上传，前端隐藏入口且服务端拒绝附件请求，防止项目 inputs 未映射至隔离运行目录却报告上传可用。

验证：Contracts/Renderer/API 类型检查与构建；Orchestrator 和 API 回归（完成后续聊、上下文/目录/上游保留、越权上传、作用域隔离、非法附件）；并发专项；隔离输入组件验收默认成员、IME、上传失败/恢复、发送失败保留、成功清空、运行态。使用临时目录及确定性 runner，不读取密钥、不调用真实模型、不重跑用户项目。

兼容：ProjectTask 新增可选 followUp（当前问题和前次 Run 引用）；旧记录无此字段走原行为，无数据迁移。回滚代码保留新上传文件及历史记录。

## 验证记录（2026-10-10）

### PC-V1.1 连续协作验收（隔离验收通过，真实模型待验收）

- PC-R5/T5：使用临时真实文件和持久化存储验证带材料执行、成果位置追问、修改原文件、失败/取消保留成果、关闭后重开继续追问。失败/取消后恢复未完成步骤保留当前对话，仅显式全量再次调度归档旧对话。确定性 runner 只替代模型生成，不把隔离验收标为真实模型验收。
- PC-R6/T6：项目流式镜像以 Run ID 关联；运行中轮询不得删除尚未入项目消息的实时回复，不得用较旧 checkpoint 缩短已显示文字或回退已完成工具。保留 invocationId、耗时、审批 ID 等原事件信息。过期 Run 事件不得覆盖当前 attempt。文本/思维增量事件增加可选 textOffset（UTF-16 字符偏移，contracts 定义）；用于去重轮询 checkpoint 已覆盖的增量，缺失段等待 checkpoint 修复，不填充虚构文字。旧事件缺省仍按原追加规则，旧消费者忽略新增字段。
- PC-R7/T7：执行前建立事件订阅并短时等待连接；API 订阅完成后立即发送 SSE 注释握手，不等待 15 秒心跳。连接失败或超时降级轮询，不阻断任务；启动失败/终态/卸载清理订阅。验证延迟 HTTP 响应、任务即时输出及失败清理。
- 边界：本期续聊仍是 ChangeSet，选中非叶员工会级联下游；不以关键词自动判定只读问答，不改变 DAG/工具授权。本轮记录该产品边界，独立问答语义需要后续明确契约。真实模型、麦克风及现有用户项目不在未确认范围内执行。
- 公共 HTTP 请求结构、持久化结构不变，SSE 增量增加向后兼容的可选偏移，无迁移；回滚镜像/订阅改动不会删除材料和成果。
