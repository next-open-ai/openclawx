# 数据对象工作台（第一期）

状态：第一期已实施并通过本地验证；验证边界见 [status.md](status.md)。范围仅 OpenClawX，不同步子项目。

## 需求与契约

- DO-R1：Excel/CSV/SQLite/JSON/API 统一作为数据对象；保留已有 ID、数据和应用。
- DO-R2：对象业务说明、连接说明、表说明和字段标注可编辑并保存最新值。**不实现 Schema 版本、兼容性或历史快照**。
- DO-R3：API 提供 URL 说明、入参/返参路径、类型、必填性与说明标注。结构与样例不混为一谈。
- DO-R4：网关提供当前对象的模型可读 Schema；应用创建和优化读取相同已保存说明。不返回认证信息或样例数据。
- DO-R5：API 同步保持匹配资源的 ID 与已有标注；使用事务更新，不丢失关联应用。
- DO-R6：工作台流程为接入对象 → 标注结构 → 预览 → 创建应用；未接入的远程数据库不伪装可用。

跨包契约：`packages/contracts/src/data-schema.ts`。新增 `PATCH /data/sources/:sourceId/annotations`、`GET /data/gateway/schema?sourceId=`；所有访问须校验用户与组织所属权。无权返回 404，标注不合法返回 400。表 Schema PATCH 增加 description。对象标注与原连接配置分开保存，不修改原文件或凭据。

## 非目标与回滚

不新增 MySQL/PostgreSQL 在线连接器、跨源联查、模型直调、任意 SQL、AI 自动标注、独立连接复用及完整操作发布平台。第一期应用仍绑定一个对象中的一张表，API 数据来自显式同步快照，不实时透传任意远端请求。

新增持久化列采用幂等加列，无破坏性迁移，旧对象默认为空说明。回滚代码保留新增列即可；原数据、归档资产不删除。权限校验与参数化执行继续保留，不属于 Schema 兼容性功能。
