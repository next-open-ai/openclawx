# 数据对象验收规格

自动化入口：`pnpm --filter @openclawx/api test`，用例位于 `apps/api/src/modules/data/data-object.test.ts`。

| 测试 | 验收断言 |
| --- | --- |
| DO-R1 | 旧数据库加列后原数据/表 ID/标注不丢；JSON 对象/数组导入；嵌套值保留 JSON 文本；无效文件拒绝 |
| DO-R2 | 对象、连接、表、字段说明保存后 API 和磁盘读取一致；旧说明缺失按空值读取，损坏说明不得静默吞掉 |
| DO-R3 | 嵌套 API 字段可标注；重复位置+路径拒绝；长度和类型校验 |
| DO-R4 | 网关 Schema 不含记录样例、认证字段和 URL 查询密钥；跨用户/组织不可读取；应用 Prompt 包含最新说明，敏感字段样例隐藏 |
| DO-R5 | API 同步前后表 ID、表说明、字段说明和关联应用不变；源字段顺序变化不串列 |
| DO-R6 | renderer 类型检查/构建；隔离真实 Vue 页面验收说明和字段编辑保存、API 参数、预览和创建入口 |

UI 人工验收：对象详情四个入口可切换；保存错误必须出现在编辑弹窗内；取消不保存；单字段长说明可换行；窄屏不撑宽页面。模拟界面可用 `node scripts/data-workbench-preview.mjs` 启动（先构建 renderer）；不会连接真实数据源或执行模型。

真实模型创建应用、真实远端 API/数据库、全 Electron 安装包验收不由模拟用例替代，须单独记录未执行项。
