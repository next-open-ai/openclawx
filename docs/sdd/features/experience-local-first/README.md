# EX-R1–R6 / EX-T1 · 本地优先经验记忆

状态：已实现并隔离验证；规格版本：1.1；更新：2026-10-13；关联：[状态与证据](status.md)、[用户手册](../../../guides/user-manual.md#experience-settings)。

触发机制：save_experience由模型按需调用或用户自然语言要求触发，不是run.completed自动保存；Pi在每轮执行前根据至少4字符的用户问题预召回一次，AgentScope只提供模型按需load_experience，DSH未接入。关闭经验功能或不具备可信运行身份的共享上下文不提供工具。知识库测试仅配置阶段管理员显式触发，不能称作经验内容真实性验证。

## EX-R7 / EX-T2 · 异步文件副本

SQLite 仍是权威持久化，保存成功须等待数据库落盘；JSON 卡片副本改为后台 fs.promises 原子写，不等待、不使用同步文件 API。队列全进程单并发、最多 64 个待写路径；同路径待写更新合并为最新内容，正在写的旧版本之后串行写新版。满载跳过新副本，失败记录不含经验内容的告警，不无限重试、不回滚数据库。返回 backend=sqlite、mirrorSaved=false、mirrorState=queued/skipped，明确排队不代表文件已保存。进程退出可能丢失待写副本，数据库不受影响；本轮不改变数据库实现或知识库流程，不承诺慢磁盘下数据库持久化零等待。测试覆盖慢写不阻塞、失败、容量、合并、顺序和实际 JSON 落盘；无数据迁移，回滚保留数据库及已有副本。

2026-10-13。save_experience/load_experience不依赖Embedding才启用。经验先写本地SQLite、再后台异步写独立JSON卡片副本；SQLite是事实源，保存返回不等待JSON副本。保存用户、组织、智能体和时间，未知来源旧文件保留并标记legacy-unknown，不冒认当前用户。首期经用户要求，组织内加载共享经验池，不按用户/智能体过滤，仍保留组织边界；未知组织旧经验不自动归属当前组织。此共享提示须在设置显示，不应记录隐私/凭据/业务明细。

仅一个系统经验知识库目标；设置保存ID并令available=false，配置阶段显式测试成功才标available=true。配置指纹变化立即使门控失效。运行阶段只读配置值，不发健康探测，不采用超时竞速判定可用性。未指定/不可用直接跳过。只支持已有文档写入能力的LanceDB/Bailian目标，复用知识库凭据，不复制到domain KV。传输自身的超时仍保留，不是运行时可用性探测。

保存返回前只等待本地持久化，远端同步后台有界执行，不阻塞对话；同步失败保留本地记录及失败状态，不自动无限重试。load和预召回只读取本地文本匹配及已完成语义缓存，不等待远端；配置可用时后台按查询预取语义命中，下次同查询可利用缓存。无语义缓存时明确backend为local-text，不伪称向量语义匹配。后台不读取无目标的知识库，语义结果仅映射本地经验ID，不注入其他文档。同步/预取任务与目标配置指纹绑定，配置切换不混缓存；API生命周期内执行，重启中断不自动重试。

契约：ExperienceSettingsSchema(enabled,knowledgeBaseId)，ExperienceSettingsState追加available/fingerprint/checkedAt；模型不能提供身份/配置。API从可信RunRecord绑定经验上下文；Pi与AgentScope宿主注册同一工具，DSH暂不接。共享/失效账号运行不给工具。无API身份的调用只能显式提供来源或使用legacy-unknown，不读取伪造的模型身份字段。

测试追踪：R1无Embedding仍两工具/本地先成功；R2SQLite及文件副本/重启读取/旧文件保留；R3假服务永不完成也不阻塞save/load、available=false零网络、队列上限及失败状态；R4用户/组织/智能体来源及共享加载、异步运行隔离；R5仅配置阶段验证/指纹变更失效/非管理员配置拒绝；R6本地文本与语义缓存标识、Pi/AgentScope工具接入。隔离测试不使用业务库、真实模型或第三方知识库。

兼容：旧经验文件不删除，新SQLite只导入旧卡片一次；原导出旧文件浏览API保留。回滚保留新库/JSON卡，不将旧版本声称为新库完整读取器。知识库写入可能已完成，不自动删除远端文档。所有测试与残余风险在status.md记录。
