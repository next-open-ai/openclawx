# MDA-SQL · AI SQL 与统一预览（2026-10-13）

取代 MDA-R2 中“新应用只能使用结构化定义”的限制，历史定义不迁移。

当前口径（2026-10-13）：SQL-R8 已取代 R3/R7 中逐次确认规则，已审核新增/修改/删除均直接提交；后台仍鉴权。SQL-R10 增加默认静态/EXPLAIN 预检查与管理员可选测试库回滚试写；MDA-R12 单独开放 MySQL 新表草稿审核，并非放开任意 DDL。下方按需求演进保留编号，冲突时以上述后续增量为准。

## 需求、任务与测试规格

- SQL-R1 / T11：AI 用对象表 ID、字段 ID 编写单条参数化 SQL（`:name`），服务端解析 AST、检查表/列/敏感标记并映射可信物理绑定；不再由结构化查询生成业务逻辑。首期 SELECT 支持 JOIN/聚合，禁用子查询、CTE、UNION、DDL、文件/系统函数、跨库标识和多语句。测试越权、注入、敏感列、参数类型、三种方言及旧定义兼容。
- SQL-R2 / T12：SELECT 真实有界测试通过后登记，失败不覆盖。SQLite 本地副本只读；MySQL/PostgreSQL 实时对象沿用所有权与凭据通道，结果最多200行/256KB，事务只读，超时取消不返回结果。
- SQL-R3 / T13：INSERT/UPDATE/DELETE 先静态验证并登记待确认草稿，不执行写入测试。仅支持单表、事务表、单行 INSERT、完整主键等值参数条件 UPDATE/DELETE；禁止修改主键。所有者管理员在可信界面确认操作摘要及 SQL 后启用，修改定义撤销批准；实际每次写入需宿主确认、当前对象写入开关和权限复核，影响超过1行回滚。模型测试工具永不执行写入。测试未批准拒绝、版本冲突、非管理员、写入开关、取消、超限回滚。
- SQL-R4 / T14：数据项目预览复用静态快照，注入无凭据 SDK，通过已登录可信宿主调用与发布页相同的数据接口。查看票据不授予数据访问，普通项目不获得数据能力。测试跨窗口消息、过期/切换、普通项目及发布行为兼容。

## 契约与存储

### MDA-R13 / T23 · 按场景注入与提示分层

智能体基础指令不改动。无数据工具的运行不注入数据提示；普通关联对象员工仅获得问数说明；数据应用运行按实际可用工具补充SQL登记/建表草稿指导。公共运行提示只说明数据访问边界及工作流程，工具描述与contracts提供具体参数/限制，API仍执行权限与SQL校验。静态页面交付约束（入口文件、无npm/CDN/直接fetch、SDK接入与绑定）独立在API交付适配模块维护，仅数据应用项目背景引用，不进入普通数据员工提示。

持久化项目背景保留用户需求、应用/对象ID及交付目标，不重复SQL语法、限制清单和CRUD审核规则；当前可用工具协议优先于历史平台协议说明，但不覆盖用户业务要求。无旧项目数据迁移或提示词覆盖，无权限/SQL能力变更。回归覆盖空工具、普通问数、应用工具子集、Pi/AgentScope共用入口、异步运行隔离，以及项目背景/交付说明分离。模型生成质量需后续人工验收，本轮不调用付费模型或业务库。

### MDA-R12 / T22 · AI建表草稿与网关结构创建

首期 MySQL 实时对象：AI工具 data_app_propose_schema 仅生成持久化草稿；1–5张新InnoDB表、每表显式主键、字段常量默认值，以及同方案新表上的普通/唯一索引。拒绝DROP/ALTER/TRUNCATE、跨库、临时表、AS SELECT、外键、任意默认函数、系统语句及注释条件执行。SQL显示实际数据库限定名；模型不执行DDL。

独立对象schemaCreationEnabled默认关闭，不继承CRUD开关。管理员配置开启后审核固定revision，明确确认“创建并加入当前对象和应用”，服务端才执行。执行前检查库内同名表、逐条持久化进度；同连接串行。MySQL DDL不伪称可回滚，部分失败/断链分别记partial/unconfirmed，重启中断执行转unconfirmed，不重试、不自动删除表。成功后重读真实Schema并在本地元数据事务中加入对象；仅用户当前确认应用扩大tableIds，其他应用不变。普通保存和对象CRUD权限不自动开启。

契约见 data-schema-change.ts；新增data_schema_changes计划表与可选绑定标志，无原库迁移。回滚关闭入口，保留计划和已创建表。验证编译拒绝、权限/版本/冲突、无模型执行工具、逐条进度、部分/未知失败、真实Schema登记、范围不扩散及UI状态。默认模拟驱动/临时SQLite，不在用户业务库建表；PostgreSQL、本地副本、旧表结构修改及外键关系自动登记不在首期。

### MDA-R11 / T21 · 全屏应用大厅

数据工作台移除重复“继续优化”按钮，统一“编辑应用”。Workmate左上角品牌按钮打开全窗口应用大厅，不销毁原工作台/项目；返回恢复原界面，账号变化关闭大厅并丢弃旧列表。首期展示当前账号已发布且可交付的数据应用，不将待绑定/无URL项目当可用应用，也不自动发布。卡片展示名称、类型、更新时间，支持搜索、最近更新/名称排序、打开外部浏览器与URL/二维码分享。打开优先本机URL，二维码优先局域网地址；无局域网地址明确提示，不把localhost二维码推荐手机使用。发布页依旧要求身份验证，URL不授予数据权限。加载/空/错误/重试、键盘返回、移动网格与减少动画完整；延迟响应不得污染卸载后的列表。测试可用应用过滤、稳定排序、导航与原工作台保留、账号隔离、打开/分享与二维码失败。仅展示与导航，无数据迁移；关闭大厅入口可回滚，不删除应用。

### SQL-R10 / T20 · 轻量 SQL 验证

写 SQL 登记自动获取当前目标表原生类型、静态检查 BIT 值与必填字段，并执行非 ANALYZE 的 EXPLAIN；只预检查、不试写。报告标记 static/explain，不冒充真实写入通过。可选事务试写仅由管理员可信配置入口发起，必须勾选“确认测试库、接受序列等不可回滚副作用”，仍需对象写入及当前 SQL 批准；不暴露给模型。检测到触发器拒绝试写，事务表单行执行后显式 ROLLBACK 成功才报回滚完成，从不 COMMIT；失败不覆盖既有批准或成功报告。报告按 SQL revision 保存，无测试参数/数据。BIT 映射整数，不再默认为文本。旧对象在验证时补查当前原生类型，不静默修改对象Schema/已批准SQL。测试 BIT字符串拒绝、数值通过、EXPLAIN未执行写、回滚无COMMIT、权限/确认/版本、触发器拒绝及回滚失败不报成功。实际业务库不自动执行验证；“回滚”不承诺序列、触发器外部状态完全还原。

### SQL-R9 / T19 · 写入错误不误报网络

数据库明确拒绝（重复键、外键、非空/缺省值、长度、日期数值类型、数据库角色无写权限、只读事务）返回安全分类建议及白名单原生错误码，不回传原始消息、参数或SQL。未知驱动/提交连接失败仍标记结果未确认，禁止自动重试。API日志仅记录应用ID、规范错误码与安全生成提示；页面不重复拼接“刷新/勿重试”，不把任何错误统一说成权限问题。测试MySQL/PostgreSQL常见拒绝与提交断链，真实业务库不重试。该任务改进诊断，不声称已定位或修复用户业务库的具体约束失败。

### SQL-R8 / T18 · 表单可用与纯网关提交

按用户要求，已审核写操作（含删除）运行时均不弹平台确认；操作审核只在配置入口进行。预览 iframe、项目静态响应 CSP 及发布 iframe 一致启用 allow-forms，让 submit 事件正常到达代码；保留 form-action:none 阻止原生表单外发，由 preventDefault 后的 SDK 经网关执行。保留 opaque-origin、身份、对象及已审核版本检查，不向页面开放凭据。测试真实浏览器点击提交触发 SDK、原生表单无法外发、无同源访问，以及预览/发布删除零确认。当前学生草稿新增状态栏显示提交中/成功/失败；只按 affectedRows=1 确认新增成功，不自动重试。真实业务库不参与测试。兼容既有 SDK，无数据迁移。

### SQL-R7 / T17 · 一次授权与动态访问状态

取代 SQL-R3 中所有写入逐次弹窗：审核批准按 SQL revision 固定，已批准新增/更新由用户业务页面提交直接执行，删除仍有危险操作确认。不自动批准、不扩大对象写入开关或账号角色。服务端每次继续复核身份、对象写入、批准版本及参数；旧 confirmed:true 兼容但不作为授权证据，新请求可省略。SDK `getAccess()` 经可信宿主请求，返回当前 writeEnabled/canWrite 与操作审核状态，无凭据；只作显示，不代替执行鉴权。宿主审核完成通知页面刷新。现有学生页面读取动态状态，去除固定“只读/待确认”断言。测试未批准/撤销/非管理员仍拒绝、新增更新不确认、删除确认、状态查询身份隔离、旧请求兼容。仅修改当前学生项目草稿，不自动覆盖绑定/发布版本，不提交业务数据。

### SQL-R6 / T16 · 应用时间与排序

应用列表显示创建时间、已绑定页面修改时间；默认最近修改优先，提供最新创建、名称排序。修改时间复用 `customSite.updatedAt`，未绑定回退 `createdAt`，不把项目草稿或查看行为伪称已交付修改；相同时间以创建时间和 ID 稳定排序。最新项显示“最近更新”，未交付项显示“最近创建”，不表示其他同名应用是其历史版本。页面内说明写入步骤，不自动开启写入或执行 SQL。测试时间回退、三种排序、同时间稳定、无效时间及不原地改变服务端数组。仅 renderer 展示，无契约/数据迁移。

### SQL-R5 / T15 · 多查询页面通道背压

普通页面一次可同时调用多个 `workmateData.query`，不以第5个请求直接失败。预览及发布共用 SDK：最多4个在途，超出 FIFO 排队；含在途最多32项，总等待120秒。队列满返回 `APP_BRIDGE_QUEUE_FULL`，排队超时不发送；失败不自动重试（尤其不重试写入）。宿主安全限制继续保留，格式错误、超长消息、并发超限分别返回 `APP_BRIDGE_INVALID_REQUEST` / `APP_BRIDGE_PAYLOAD_TOO_LARGE` / `APP_BRIDGE_BUSY`，不合并误导提示。结果失败携带可选 code，SDK Error.code 兼容旧消息。测试一次6项、32项容量、超时/失败释放容量、外部窗口忽略及宿主拒绝分类。仅修改桥接，不改业务页面、SQL、权限或实际数据库；无持久化迁移，回滚 SDK/宿主文案即可。

新增 `data_app_register_sql` 工具及 SQL operation Zod；历史结构化工具保留。参数仅标量值，无法替换表/列/SQL。新增批准记录按定义 SHA256 固定，确认 API 不暴露为模型工具；运行时仅接受 operationId/parameters。SQL 定义持久化，不保存测试行、凭据或测试参数。预览不隐式发布、不自动启用写入。

## 兼容、回滚与验收

增量表和可选能力；回滚时关闭 SQL 登记入口与预览桥接，但保留新旧定义联合读取，不删除已有数据/定义，也不能直接退回不认识 SQL 定义的旧二进制。真实业务数据库、模型生成及桌面端最终体验需人工验收。测试使用内存 SQLite、合成远程驱动与临时项目；不得对用户实际数据库执行写入验证。

首期不支持批量写入、跨连接、DDL、子查询/CTE/UNION；本地副本只读。SQL 采用 MySQL 基础语法解析，再按实际引擎序列化；函数的数据库兼容性仍须通过真实查询验证。原生标识符仅接受字母、数字、下划线、美元符、空格及连字符，特殊名称暂用历史结构化路径。尚无跨请求幂等或旧值乐观并发校验；写入连接中断时提示结果未确认、先刷新核对，禁止自动重试。
