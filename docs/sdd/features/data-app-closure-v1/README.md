# 数据应用交付闭环验收

范围仅 OpenClawX。本阶段验证数据对象 → 最新标注 → 应用准备 → 工作区 HTML → 绑定 → 同源取数 → 原应用优化。不引入 Schema 版本、实时原库查询或跨表联查。

## 需求、任务与契约

- DAC-R1 / T1：应用交付状态由服务器事实派生：template-ready、awaiting-binding、custom-ready；不得将尚未绑定的定制应用伪装成模板站。不推断 Agent 正在运行或已经失败。
- DAC-R2 / T2：定制页面未绑定时发布链接展示明确等待页；首次绑定后可用，失败重绑保留当前页面。优化在原 appId 上继续，使用最新 Schema。
- DAC-R3 / T3：隔离合成数据验收导入、标注、真实工作区工具写入/绑定/导出、HTTP 页面取数、最新 Schema 优化、非法 token 和跨用户访问。模拟模型结果不得宣称真模型验收。
- DAC-R4 / T4：界面明确待绑定状态及继续创建入口，保留模板流程与旧应用。用户业务数据不参与测试。
- DAC-R5 / T5：在新临时目录构建桌面资源与未签名应用目录，使用安装资源中的 API 和 Electron 内置 Node 做启动/数据应用冒烟；不得覆盖既有 stage/release，不启动主窗口触碰用户存储，不将此冒烟等同完整安装/真模型验收。
- DAC-R6 / T6：数据目录按名称、类型和说明搜索，区分分类空态与搜索无匹配；提示可关闭且失败为 alert。详情用实际说明/字段数提示下一步，不将标注数量作为质量评分或创建门禁。待绑定应用以继续创建为主操作、不显示分享二维码；已交付应用以打开应用为主操作，分享与删除收起至更多操作。状态不推断运行中/失败。
- DAC-R7 / T7：创建弹窗允许选择当前数据对象中的表；默认名称，模板/AI 模式差异明确、提供可编辑需求示例；失败在弹窗内显示，保留输入，提交期间禁止重复提交/关闭。成功创建与列表刷新分离：刷新失败仍保留已创建应用并继续原定操作，不再次调用创建。定制创建不自动打开未交付的数据管理界面。只改 renderer，不改模型/编排/API/权限。
- DAC-R8 / T8：离开工作台后，在本次登录期间返回原对象、表、页签和目录搜索；返回重新读取服务器数据和应用状态，不缓存数据、密钥或应用令牌，不推断运行状态。刷新保留当前表；对象已删除回到目录并提示，表已删除选择首表。读取失败保留可重试的位置；注销/换用户清除导航且拒绝旧页面回写。仅 renderer 内部 props/event，无 API/存储变化。

契约：`dataAppDeliverySchema` 位于 contracts。应用响应新增可选 delivery，旧客户端仍可读取。持久化仅新增 creation_mode（默认 template）；已有定制绑定页仍由 HTML 事实识别。不追溯猜测旧的未绑定应用。

## 测试规格

API 回归：模板立即就绪；新定制等待绑定且发布页不是模板；真实工具绑定/导出；绑定后 HTTP 数据与网关相同；更新字段说明后 optimize prompt 使用最新标注且 appId/token 不变；无效绑定不替换旧版；非法 token 与跨用户拒绝。

浏览器：真实 API 隔离数据应用加载、过滤、错误状态、修改后的页面取数。真实模型测试另记录供应商/模型、数据边界、结果；缺少授权登录环境时标为未执行，不用手写页面替代真模型结论。

交互回归：`node scripts/data-workbench-ux-regression.mjs` 验证状态对应动作、旧应用回退、名称/说明搜索和下一步建议。界面验收使用隔离合成数据，不读写业务数据；检查搜索无匹配/清除、字段说明入口、未交付隐藏二维码、已交付分享收起、长名称及窄屏不撑开页面。

DAC-T7 验收：`node scripts/data-app-create-regression.mjs` 运行真实 Vue setup 处理函数配内存 API 适配器。创建表选择默认当前表、请求只引用选中表；模板无需需求，AI 必须有非空需求；创建失败保留弹窗输入；成功后列表刷新失败有明确提示且仅创建一次、仍触发对话或打开模板。浏览器故障夹具：`OPENCLAWX_DATA_PREVIEW_FAILURE=create-and-refresh node scripts/data-workbench-preview.mjs`，首次创建失败，重试后列表刷新失败，只使用内存数据且不调用模型，不宣称真实模型验收。

DAC-T8 验收：同一 Vue setup 回归验证卸载导航快照、返回第二张表/应用页签并读取新的 delivery、刷新保留表、对象/表删除回退、读取失败后重试、过期请求不得覆盖选择、卸载后不写入状态。App 层按登录身份隔离导航；无模型调用。

打包回归入口：`node scripts/data-app-packaged-smoke.mjs`（先完成 `pnpm build`）。临时 stage 的数据库驱动及其依赖须可加载，安装资源 API 无工作区 node_modules 依赖即可启动；正常登录、导入/标注/定制状态/绑定/取数/优化可工作。临时 stage 路径已存在时拒绝覆盖。运行后仅删除本脚本创建的临时目录。

## 回滚

幂等加列，无删除/覆盖旧应用或数据。回滚保留 creation_mode 列；HTML 修订机制沿用现有实现，与数据 Schema 版本无关。
