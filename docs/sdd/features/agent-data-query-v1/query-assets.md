# QA-R1–R5 / QA-T1 · 用户主动保存查询资产（2026-10-13）

首期只读，独立于经验记忆。已成功执行的普通结构化查询、数据应用SELECT产生服务端回执，最多保留同一私有会话最近5条、7天有效，不保存结果明细。仅本轮真实用户消息明确要求保存/收藏查询时，模型获得保存能力的许可；否定、疑问、条件、引用或歧义指令保守拒绝并提示明确说“保存这个查询为…”。工具参数不能提供授权。回执跨轮有效，只属于相同用户/组织/会话，不接受模型提交SQL作为成功证明。

资产保存名称、原问题、用户要求的业务口径备注、只读定义、参数定义、对象/表依赖、Schema指纹、时间及版本1。仅标记execution-verified，不等于业务正确或用户已验收；不自动保存资产，不自动生成Skill。SQL保存去除测试值及默认参数值，结构化查询保留原筛选值并明确不可用运行参数覆盖。成功回执并非查询资产，不建第二套完整对话历史。

按org/user命名空间持久化于API单写者domain KV，每用户最多200个资产，同回执同名保存幂等。宿主Tools保存、名称搜索、重新运行；认证HTTP列表/删除用于后续管理界面。运行必须重新验证活跃账号、员工对象关联或当前应用表范围，以及对象所属权、敏感标记、Schema指纹；Schema变化拒绝并要求重新查询后保存，不自动修复。SQL只经现有网关只读分支，不授予普通问数临时任意SQL能力；当前SQL语法限制仍保持。分享/跨组织/自动向量检索/默认值编辑/业务验收/管理UI暂不做。

测试：QA-R1明确意图及误触防护；R2跨轮回执/失败无回执/不保存明细/版本幂等；R3跨用户组织会话拒绝、关联撤销与应用范围；R4SQL去测试值/默认值、结构化参数拒绝、Schema变化；R5列表/删除/工具注册及普通无数据运行隔离。使用临时KV/合成驱动，不访问业务库或真实模型。无已有数据迁移；回滚移除入口，保留已存资产及回执自然过期，不覆盖经验存储。
