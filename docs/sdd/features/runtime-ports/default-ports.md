# RUNTIME-PORTS-001 · OpenClawX 默认端口隔离

状态：已实现，工程验证通过。

## 需求

- 本地开发界面不得继续使用前端工具常见的 `5173` 端口。
- OpenClawX 界面默认监听 `127.0.0.1:47831`。
- OpenClawX API、桌面内置服务、Gateway 默认连接和容器服务统一使用 `47832`。
- `OPENCLAWX_API_PORT` 等显式环境变量继续优先于默认值，便于部署覆盖和测试隔离。
- Vite 代理、桌面启动器、打包后 `file:` 页面、内部回调、Docker 暴露端口及用户文档必须保持一致。

## 兼容与迁移

- 这是默认端口变更，不迁移业务数据。
- 使用默认配置的开发者重新启动 OpenClawX 即可。
- 外部脚本、反向代理或防火墙若显式引用旧端口，需要改为 `47831/47832`，或继续通过环境变量覆盖 API 端口。
- 回滚时可恢复旧默认值；业务存储格式不受影响。

## 验收

- RUNTIME-PORTS-T1：活动源码、启动配置和当前文档中不存在旧默认界面端口 `5173` 或旧 API 端口 `4328`。
- RUNTIME-PORTS-T2：Renderer 开发命令监听 `47831`，代理到 `47832`。
- RUNTIME-PORTS-T3：API、桌面进程、Gateway、打包 Renderer 与 Docker 默认值均为 `47832`。
- RUNTIME-PORTS-T4：相关包类型检查、构建和端口回归脚本通过。
