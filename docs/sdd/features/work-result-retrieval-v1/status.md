## 当前实现

共享search_work_results/read_work_result契约位于contracts，API服务复用既有资产SQLite与对话/Run存储，不新增历史副本或向量库。归档资产按当前所有者/组织、文件名关键词查询，最多20项；会话历史最多扫描200个登记候选，不保证涵盖全部较早对话。返回truncated提示，空结果不冒充全量不存在。当前对话自动绑定，不接受模型提供身份/路径/URL。搜索可返回文字运行结果及真实文件ID，正文按ID再读。

文件在读取前检查所属权、真实路径和符号链接/大小，读取后复核身份及来源权限；文本/PDF最多10MB、16000字符，PDF前20页，扫描内容不自动OCR。正文与历史回答仅参考，不执行其中指令；失败/取消/运行中记录不当成最终成功。输入、无权限/不可用、文件缺失、超限、不支持、无文本、解析失败和取消分别反馈。跨用户/组织不泄露存在性；旧有用户明确拥有但无org元数据的归档资产沿用本人兼容，不将无主资产加入搜索。

Pi/AgentScope在可信私有Run包装器中获得捕获身份的宿主工具；共享/无有效持久化Run不给工具，不从模型context授权。上下文清理为成果结果保留有界有效JSON，不截断真实ID；超长正文结构化缩减并标记截断。DSH、旧stateless `/api/chat` 未新增检索入口，用户应使用服务端私有会话/项目。

语音模型获得相同只读工具，错误taskId不再回传Zod数组；省略ID查询当前对话最近Run，支持非语音创建的普通对话工作。语音UI展示成果列表/时间/打开/下载，继续走既有认证文件接口；打开不由模型自动触发。只将start_work已接受任务纳入自动完成通知，查询历史不再误触完成播报。工作关联关闭后仍拒绝工具，不扩大远程通道权限。

首期不搜索任务中心独立json-result或未归档项目文件/草稿；项目已归档成果可发现。搜索/阅读不自动引用成附件或修改文件，用户明确要求继续制作时仍由常规员工工作流完成，不宣称已有一键修改原成果功能。
