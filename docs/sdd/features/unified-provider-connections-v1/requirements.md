# UPC-001 · 统一 Provider 连接

> 状态：第一期工程实现与回归完成，待真实 Provider 验收 · 2026-10-07

## 目标

- UPC-R1：所有厂商使用同一套“厂商模板 → 连接实例 → 服务端点 → 模型”的管理结构，不强迫不同厂商共享同一种凭证或协议。
- UPC-R2：普通用户只选择厂商、服务类型并填写必要凭证；官方端点由系统自动派生，Base URL 仅在高级设置中覆盖。
- UPC-R3：一个连接可共享一组凭证并承载多个端点；同厂商凭证不同的产品线使用多个连接实例。
- UPC-R4：运行时按模型能力选择对应端点；没有专用端点的旧配置继续回退到原 `baseUrl`。
- UPC-R5：阿里百炼支持共享/业务空间域名及 HTTP、原生 HTTP、Realtime、Inference 端点；火山区分方舟大模型与语音服务；智谱作为正式模板支持对话、视觉、图像与嵌入能力。
- UPC-R6：密钥仍由既有安全存储管理；端点、服务类型等非敏感元数据可持久化，迁移不得暴露或复制密钥。
- UPC-R7：服务类型列表按供应商和 Workmate 已完成的适配动态收敛；尚未形成调用闭环的厂商能力不得仅因上游宣称支持而出现在普通用户界面。
- UPC-R8：新增连接主流程只展示供应商、必要的服务选择和凭证；连接名称、Workspace 与官方 Base URL 使用默认值并置于高级设置。已适配厂商保存后直接准备推荐模型，不再要求用户选择自动配置开关。
- UPC-R9：实时语音的凭证、端点、模型与音色归入统一 Provider/模型和能力默认项；语音体验页只保留通话行为、声音表现、复刻管理与测试。运行时优先读取统一配置，旧语音配置仅作兼容回退。
- UPC-R10：通义千问与 OpenAI 这类共享一套凭证的供应商固定按“综合服务”处理，普通流程与高级设置均不展示服务类型。如不同业务空间、密钥或网关确需隔离，则新增另一个综合连接；历史拆分连接仍保持可读与可用。
- UPC-R11：发现旧版火山实时语音密钥且尚无统一实时模型时，管理员加载模型配置即自动创建火山实时 Provider、实时模型、默认音色和能力绑定，并将密钥转存安全存储；旧文件保留用于回滚。实时模型行提供“进入通话测试”，复用完整语音体验与火山专属功能。
- UPC-R12：设置导航不再提供独立“语音”页；实时语音的模型参数、音色、通话策略、复刻管理和测试统一呈现在“模型”页的实时语音区域。底层仍分别保存连接、模型、偏好与音色资产。
- UPC-R13：实时语音运行时采用供应商协议适配器注册表；统一会话只依赖建连、会话配置、音频、文本、工具调用和关闭契约。首期支持火山 SeedDuplex 与阿里 Qwen Realtime，新增供应商不得修改公共路由或客户端传输协议。
- UPC-R14：实时模型的推荐模型、默认音色与配置说明必须随 Provider 动态变化。阿里综合连接可以直接承载实时模型；火山使用实时语音连接。自定义模型和已授权复刻音色 ID 始终允许保留。
- UPC-R15：实时会话必须显示当前 Provider、模型、通话时间和用量口径。上游返回 usage 时展示真实 Token/字符计量；未返回时仅展示本地输入/输出音频时长，不得把估算值冒充账单或自动推算费用。

## 2026-10-14 · 两场景与凭证交互增量

2026-10-14 增量 UPC-R16：普通界面仅提供综合模型/语音两场景，火山语音包含ASR和Realtime；旧service=realtime及端点保留，不改存量凭据。旧版TTS的App ID是该能力补充项，不阻止API Key语音连接保存；缺失时不自动登记旧版TTS。UPC-R17：新增/编辑API Key默认遮蔽，可用明确按钮显示/隐藏，关闭/切换连接或供应商后恢复遮蔽，不写入持久配置或日志。UPC-R18：通义自动推荐图片生成qwen-image-2.0（DashScope multimodal）及识别qwen-vl-plus（OpenAI兼容），默认公共端点、Workspace可空；保留已有手工模型/绑定，重跑推荐只补齐。

任务UPC-T15/T16：覆盖两个可见选项与旧实时连接兼容、Key显隐及重置、阿里模型/协议/空Workspace/幂等/原绑定保留；运行推荐回归、renderer构建、手册生成与docs构建。真实厂商调用不在隔离回归中。回滚只恢复UI/推荐清单，不删除已登记连接或模型。

## 非目标

- 实时语音仍使用专用低延迟会话运行时，不迁移为通用 Tool；仅统一其配置事实源。
- 本期不实现厂商控制台远程发现所有产品和配额。
- 本期不删除旧的实时语音文件；新配置成为首选事实源，旧设置保留兼容回退。

## 验收

1. 新建连接时可选择服务类型，默认地址无需用户填写。
2. 阿里综合连接能为不同能力派生正确协议端点。
3. 火山方舟和火山语音能作为同一厂商的不同连接实例存在。
4. 智谱可自动配置推荐模型并正常使用默认官方端点。
5. 旧 version 3 配置无新字段时加载、保存、调用行为不变。
6. 火山实时语音连接保存后自动建立实时模型与能力默认项；通话、手机语音和音色复刻均使用该连接密钥。
# Workspace ID 默认策略

- **UPC-R14**：通义千问 Workspace ID 为高级可选项，默认空值；标准模型不得因其为空而阻止保存、测试或调用。
- **UPC-R15**：界面应说明默认业务空间、需要填写的例外场景，以及权限/资源错误的排查方向，不得暗示生产环境必须填写。
