## 兼容与回滚

application、agentStatus、taskName 为可选增量字段；旧模板/运行记录无需批量迁移，不自动改变现有任务计划。新发布版本固定参数/报告快照，草稿编辑不覆盖历史。回滚可恢复旧构建并停用新任务应用入口；已创建任务和计划属于既有任务数据，应先在任务管理停用计划，不能靠回滚代码声称撤销已执行的副作用。

## 需求与契约

TA-R10/T10：运行记录点击打开相同TaskRunMonitor，严格固定taskId/runId，不在列表内展开结果。监控内提供执行日志、结果报告、result-json三个视图；报告按该次运行读取，JSON显示/下载服务端jsonResult完整快照（含输入/输出/状态），不是仅output.data。完成后可切换查看，失败/进行中也可查看已有JSON；无报告/缺少JSON明确空态。报告使用现有隔离iframe，读取失败可重试。切换历史运行/关闭中止报告读取并丢弃过期响应，不能串到最新运行。各入口共用查看能力，不执行任务。

TA-R9/T9：立即运行时打开独立深色科幻监控窗，按taskId/requestId观察原任务记录；应用launch获得taskId后接入同窗。轮询复用已认证任务详情/关联run只读接口，有请求截止、无并发叠加、切换/关闭中止读取但不终止任务。显示服务端真实步骤、排队/审批/完成/失败、耗时、工具摘要日志及有界输出；无记录只显示等待确认，网络失败不冒充任务失败，不伪造百分比/日志/Token。终态停止自动请求，重开/手动刷新可读取记录；仅当前关联run，不显示思考链/原始工具参数或系统日志。支持审批对话、完成后查看报告，移动布局及减少动效。UI回归覆盖精确run匹配、网络失败/终态、关闭无取消副作用。

TA-R8/T8：任务列表行提供编辑、立即运行和删除；名称/查看记录打开独立详情弹窗，不在列表内展开。编辑直接读取对应任务最新版本，在现有弹窗保存，成功回列表并反馈；取消不更改任务。行内立即运行不需要先打开详情，仍按任务ID独立复用失败提交编号，正常再次运行使用新编号；反馈含任务名，不自动弹出编辑或详情。记录、报告及审批入口保留在详情弹窗。只变更UI，不修改运行/权限/删除契约。

TA-R7/T7：撤下旧模板管理及从模板新建任务全部用户流程，关闭公共旧模板定义创建/非direct任务创建接口（410）；新任务仅通过任务应用launch或直接创建。保留应用内部的定义/发布/快照与已有任务只读兼容API，旧任务参数编辑不得变成新建入口。任务创建后及运行完成后仍保留同一任务ID，可编辑名称/参数/提示词/计划、用新requestId再次运行、删除并停止后续计划；旧运行结果不随任务修改改变，删除保留历史。一次计划执行完成后也允许手动再次运行和编辑。界面来源只显示“任务应用/直接创建/已有任务”，不再展示模板概念。

TA-R6/T6：应用运行改为全屏分步工作区：填写参数 → 执行设置 → 运行记录；设计预览为填写验证参数 → 验证发布。参数页独占内容区域，不与执行设置并排/堆叠，不套固定高度带边框的预览框。保留隔离iframe及SDK，步骤返回用v-show保持未提交表单；参数确认校验通过才前进，失败留在本步；执行失败保留设置和重试ID，成功进入记录，不在返回/切步时执行。没有定制参数页也支持可选补充说明。服务端权限及执行协议不变。

TA-R5/T5（智能体选择修正）：执行智能体选项用既有 employeeDisplayName 解析自定义名称与内置 nameKey，跟随语言切换，隐藏系统角色。列表异步到达或选中项消失时，保留有效选择，否则优先 general、再取首个非系统员工；没有可用员工显示空态并禁止创建，不能提交隐藏的默认 ID。回归使用真实 PRESET_EMPLOYEES，并覆盖自定义员工、异步列表和空列表。

TA-R1/T1：任务中心新增“任务应用”业务入口，一个应用对应一种任务。以现有自定义任务模板定义为事实源，application可选标记区分旧模板。创建输入name/description/employeeId/prompt，生成参数编辑项目；内置TASK-API-REFERENCE.json作为AI编程参考，复用参数Schema、platform提交SDK和受控数据查询。无需新项目运行时，页面不能直接持有凭据或任意写入接口。编辑后返回自动导入草稿；发布须显式验证与发布，验证不执行模型、不创建任务。旧模板管理和已有任务保留。

TA-R2/T2：打开应用填写参数，选择立即执行或现有TaskSchedule定时计划。宿主调用应用launch接口，服务端固定已发布版本、校验参数和权限，按requestId持久化请求指纹、稳定taskId，重试不重复创建/执行；相同ID不同参数409。立即执行异步202返回taskId/runId，轮询任务记录，失败可查看原因；定时复用15秒服务端调度器。应用内运行历史、默认/快照报告与JSON读取复用原接口；iframe提交不直接执行任务，宿主操作明确确认。

TA-R3/T3：智能体任务queued继续等待；waiting-approval保留运行中及agentStatus并提供执行对话入口；按同一turnId追踪审批续跑的新runId并回写原任务结果。服务重启只对已持久化关联智能体的运行恢复观察，不重新提交消息、不重放Skill副作用；无关联的中断仍明确失败。30分钟总截止沿用原开始时间。运行结果固定模板/参数/报告快照。

TA-R4/T4：UI持续显示加载、空、失败、成功、发布状态；创建/编辑/验证/发布/运行按钮分清语义，错误保留参数，未发布不可运行；页面离开不取消任务。输入JSON和脚本视为不可信资料，数据API仍服务器授权；创建项目不自动执行AI。旧结果/模板字段兼容，无数据迁移。相同业务同步EasyMate，不引入多Agent/其他引擎。

## 范围与验证

不增加任意任务API代理、网页定时器、凭据注入、自动发布或数据库权限。项目编辑来源仍使用现有返回模板通道，新任务应用根据application标记恢复对应入口。任务应用不等于公开发布网站，首版在已登录任务中心打开；移动公开URL/应用广场独立交付。原模板验证/版本/所有权锁保持。

测试：共享契约、应用create/edit/validate/publish/launch/同ID重试/指纹冲突/跨用户拒绝/定时/版本快照、真实脚本桩排队/审批续跑/重启观察、UI参数提交与反馈。执行contracts/core依赖构建、orchestrator/API test、renderer构建及隔离UI回归、文档检查；不使用真实用户任务或模型凭据。完成状态按实际证据回填。
