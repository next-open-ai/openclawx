# 轻量项目闭环验收

更新：2026-10-11 · 关联任务：LP-T1–T6、PA-T1–T6

规格入口：[轻量项目](../../sdd/features/lightweight-project-v1/README.md)、[静态应用发布](../../sdd/features/project-application-v1/README.md)。本页是验收操作入口，不另定义产品行为。

## 自动回归

在仓库根目录执行 `pnpm project:regression`。需要 Node 22+、已安装的工作区依赖和 Playwright/浏览器；非默认位置可用 `OPENCLAWX_PLAYWRIGHT_MODULE` 指定 Playwright 模块、`OPENCLAWX_BROWSER_CHANNEL=chrome` 使用本机 Chrome。

命令依次运行编排/API 测试、前端构建、项目创建/输入框/预览发布浏览器回归，失败立即停止。构建必须先于浏览器回归完成，避免 Vite 清理产物导致测试读取 CSS 失败。

自动回归使用临时目录、确定性 runner 和测试身份，不读取真实密钥，不调用供应商，不发布真实项目。原生目录选择通过 IPC fixture 验证，不等于操作系统弹窗验收。浏览器发布回归使用真实 Vue/Fastify、ProjectService/RunEngine 与临时持久化存储：先生成，再修改两轮，检查材料、回复上下文、固定成果目录以及发布版本隔离。API 回归另覆盖失败、取消、重启后续聊与显式更新发布。

## 真实模型 / 桌面验收（待执行）

使用新建的专用测试项目和无敏感信息的材料，勿复用正在工作的项目。启动应用后确认实际员工、模型、工具权限；真实调用可能计费。记录日期、应用版本、供应商/模型、耗时和界面提供的 usage，不记录密钥、完整提示或材料正文。

1. 新建项目，分别检查系统目录、自选父目录；取消选择不丢草稿，原父目录文件不变，创建不调用模型。
2. 上传一份测试材料，发送：“根据材料创建一个可交互的静态网站，交付 index.html 和相对路径资源。”执行时检查实时文本、工具状态、停止按钮与成果树。
3. 连续发送：“保留现有内容，调整配色与布局。”、“保留前两轮成果，增加一个页面内筛选交互。”检查历史上下文延续、独立 Run、固定目录与资源完整性。
4. 预览，检查 CSS/JS、空态和窄窗口；确认发布后再次修改。未确认更新前，已发布版本必须保持原样。
5. 在新一轮执行中点击停止，检查取消原因和旧成果保留，再发消息验证可继续。失败场景保留诊断，不将上游异常直接解释为用户网络问题。
6. 等待所有任务结束后关闭并重开应用，检查项目目录、历史消息和发布记录，再发一轮修改。重新打开发布版本应换发查看链接；旧链接重启后失效是预期行为。

本地静态发布不运行后端，也不替代数据工作台发布或公网部署。不要用需要数据库/API 联网的应用验证静态发布成功。
